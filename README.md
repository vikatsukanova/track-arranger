# Track Arranger

A free, open-source, non-AI tool that turns a stuck 8-bar loop into a full arrangement plan.

Status: early MVP, drum and bass only. Enter a BPM (around 174) and get an arrangement map (intro, build, drop, breakdown, second drop, outro) with bar lengths, rule-based production tips for each section, and a MIDI file with section markers and labelled placeholder clips to drag into Logic or Ableton.

Built in Python as a learning project.
